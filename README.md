# AIMcoffee — Веб-сайт кофейни

### ☕ Описание проекта
Современный и эстетичный сайт для кофейни "AIMcoffee". Проект включает в себя интерактивное меню, блок о компании и форму обратной связи.

### 🛠 Технологии
* **Frontend:** JavaScript, CSS (Custom Properties), HTML5.
* **Дизайн:** Акцент на визуальную составляющую и пользовательский опыт (UX).

### 🌟 Основные функции
* Интерактивное меню с категориями напитков и десертов.
* Секция с историей бренда и ценностями компании.
* Адаптивность под любые размеры экранов.
